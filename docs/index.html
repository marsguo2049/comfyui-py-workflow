HOW IT WORKS

一次输入，两次确认，本地完成

规划和渲染分开执行，适合显存有限的个人电脑，也让昂贵的生成任务始终由用户决定何时开始。

  1. 1
    输入故事与素材

    读取本地文档或直接输入想法，可附一张参考图。

  2. 2
    本地规划并确认

    LM Studio 建议时长、镜头和模型专用提示词。

  3. 3
    ComfyUI 逐段生成

    按确认后的计划生成关键帧、首尾帧视频与成片。

  4. 4
    查看本地结果

    在浏览器预览媒体，并可直接跳转到输出目录。
